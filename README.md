# LLAPUDP

This Arduino library was branched from LLAPSerial

Modifications made to support sending and receiving messages over LLAP

Installing

On https://github.com/jem-green/LLAPUDP at the bottom right you will find a button called "dowload zip"
Extracting this zip will give you a folder called LLAPSerial-master
Rename this to LLAPUDP
Move this to your libraries folder inside your arduino sketchbook. On windows this would be something like C:\Users{user}\Documents\Arduino\libraries\LLAPUDP
Restart the IDE
Examples can then be found under File->Examples->LLAPUDP
